CINEOSIS

B → CHAT: Talk to the AI. "make an idea" → "write script" → "break into shots" → "render shots". Configure your API key via the KEY button in the status bar to enable the AI engine.

B → SCRIPT: Edit the script directly. Save and push to shots.

A → SHOTS: Each shot has its own BEFLIX animation program. Tap RENDER on any shot to generate + animate it individually. Tap RENDER ALL to process all shots in sequence. Tap EDIT on a shot to open the full BEFLIX code editor.

BEFLIX EDITOR: Full code editor per shot. RUN executes the current code. REGEN asks Gemini to write new BEFLIX for this shot. REFERENCE shows the command syntax.

C → COLOR: Draw on canvas. Pen, box, erase. 8 ink levels. Text stamp.

D → SAVE: Export WebM, MP4, GIF, PNG, contact sheet, story text.

TIMELINE: Tap frame to navigate. Tap current frame to enter SEL mode. Frames tagged with shot ID — selecting a shot jumps to its frames.

Keys: Space=play, ←/→=step, 1-4=tabs, Cmd+Z=undo, Esc=close.
