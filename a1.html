CAUSALITY · GEMINI PRO

B → CHAT: Talk to Gemini. "make an idea" → "write script" → "break into shots" → "render shots". Add your Gemini key via KEY button for full AI. Works in local mode without a key.

B → SCRIPT: Edit the script directly. Save and push to shots.

A → SHOTS: Tap RENDER on any shot to generate + animate it individually. Tap RENDER ALL to process all shots in sequence. Tap EDIT on a shot to open the full BEFLIX code editor.

BEFLIX EDITOR: Full code editor per shot. RUN executes the current code. REGEN asks Gemini to write new BEFLIX for this shot.

C → COLOR: Draw on canvas. Pen, box, erase. 8 ink levels. Text stamp.

D → SAVE: Export WebM, MP4, GIF, PNG, contact sheet, and standard A4 Print Flipbooks.

TIMELINE / EDL: Long-press a frame to start selection range. Shift+Arrow keys. Right click on frames for structural annotation/collapsing.

Keys: Space=play, ←/→=step, 1-4=tabs, Cmd+Z=undo, Esc=close.
